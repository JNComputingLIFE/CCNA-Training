ACCESS CONTROL LISTS

General - bind extended access lists as close to the router as possible 

there is a lot of ip/subnet things going on under the hood.

Recommendation: 
- use show ip interface brief to 

- access-list ? to see access lists, extended acls, and expanded range versions

when permitting protocols, (goal here is to access or not http server):
App is http, transport is tcp (at least a cpt is concerned). network is ip,
data link in ethernet, physical is cat6

- access-list 100 permit tcp host 10.1.2.101 host 10.1.1.100 eq 80

1st host is source, 2nd is destination. eq is just an operator function to give acl. 80 is http. 


"Router1(config)#do sh run | include access
