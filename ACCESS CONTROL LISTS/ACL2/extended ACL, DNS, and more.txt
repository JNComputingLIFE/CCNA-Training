REGARDING RETURNING TRAFFIC (FROM  HTTP)

- issue is: http as app layer protocol doesn't just send tcp with source port 80.
Maybe we can have ftp traffic too so do not for compatibility's sake note it down with source port. Certainly an advantage of named commands.


- trivia: access-list 101 permit tcp any 10.1.2.0 0.0.0.255 established 

"established" means setting ACK bit. So TCP three way handshake 
 - > USUALLY SIN BIT IS SET. THerefore on returned packet set up ACK traffic.

 it solves your problem for cisco lab. Issue: in real life, hacking tools can easily spoof your ACK.  That is why stateful firewalls are valuable.

 - this does solve your problem though, allowing return traffic like DNS resolves or just general http data to come back from server....
