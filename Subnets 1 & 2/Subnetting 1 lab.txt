first note that we need 4 subnets therefore you can use 
2^n formula to steal bits from host (2 ^ 2 bits). Therefore, your hosts start at 0 and get values that require you to take two bits, increasing the mask:

192.168.1.0/26
192.168.1.64/26
192.168.1.128/26
192.168.1.192/26

(due to 00 000000, you do a bitwise and basically on the last addresses.
compare 11 to 00 01 10 11. BITWISE AND gives 0, 64, 128, 192)

NOTE: it is easy to figure broadcast when you know next network. Just subtract 1 from next network.

if you needed to define the hosts you would use 2^n - 2 since 
host cannot get subnet/broadcast address.

In a subnet, when you assign first and last host, note that first determine network and its mask. last host is 1 less than broadcast. subnet is 1 less than 1st host.

if one less than subnet addr. then that is broadcast of prev. subnet...

practice when giving hosts addresses like switches, routers and so on:

1. if router connected to switch with devices, it gets last host
2. then switch gets 2nd last host and so on

CONFIGURING THE ROUTERS:

for each subnet, give the routers last ip. 
So for 192.168.1.0/26, next subnet is 64. broadcast is 63. last host is 62.

use cisco commands
- show ip interface brief
- conf t 
- int g0/0/0
don't forget no shut
- ip address 192.168.1.62 255.255.255.192
- don't forget to end when done

CONFIGURING THE SWITCHES:
- just do 2nd last ip in subnet
- enable, conf t, in config: host S1 (or some other name), int vlan 1 (default selection), no shut and then add 2nd last ip
- it should also have a default gateway to the router...
ip default-gateway 192.168.1.62 

end, then test if connects to router.
If so, then write. The command write saves switch config.
